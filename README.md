# За Чертой · 2035 — лист игрока, ГМ-панель и бой

Приложение-компаньон для настольной ролевой игры: лист персонажа у игроков,
панель у мастера, общий бой, чат и лог бросков. React (CRA) и свой
realtime-сервер на WebSocket. Основа — Nox Aeterna (`nerkusa/noxaeterna2-0`):
боевая механика взята оттуда целиком.

## Что внутри

- **Лист игрока:** шапка-досье (Здоровье, Доза, еврорубли, молва) и вкладки
  «Навыки», «Бой», «Браслет», «Тело», «Сумка», «Чат и лог», «Лор», «Памятка».
- **Бой:** атака, уклонение, щит, урон по типу и броне, зоны и прицел,
  прочность оружия, два оружия, боеприпасы, инициатива, страх и Воля.
- **Новое:** браслет и кассеты (копии, слепки, палёнки, шум), солюшны
  (протезы, насадки, вживляемое), Доза и болезни, «Депо».
- **ГМ-панель:** отряд, выдача из каталога, бестиарий, каталог, редактор
  эффектов, профессии, лор и карта, история мастера.

## Запуск локально

1. Сервер:
   ```
   cd server
   npm install
   GM_LOGIN=master GM_PASSWORD=secret npm start
   ```
   Слушает `ws://localhost:8788`. Данные — в `server/data.json` и
   `server/users.json`; пути меняются переменными `DATA_FILE` и `USERS_FILE`,
   порт — `PORT`.

2. Клиент:
   ```
   cp .env.example .env
   npm install
   npm start
   ```

3. Тесты правил:
   ```
   npm test
   ```

## Вход

Один общий мир на сервер. Мастер входит логином и паролем из `GM_LOGIN` и
`GM_PASSWORD`. Игроки регистрируются сами; персонаж создаётся при первом
входе и привязан к логину. При первом входе мастера в новый мир добавляются
стартовый каталог и бестиарий.

## Что видит только мастер

Палёнку (игроку она показана оригиналом), Отпечаток слепков (игрок видит его
только с планшетом в сумке), точное Здоровье при «Немоте», скрытые броски —
они пишутся в «Историю». Это скрыто в интерфейсе: сервер отдаёт данные мира
всем подключённым, как и в базе.
